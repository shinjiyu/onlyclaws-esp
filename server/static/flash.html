浏览器烧录并绑定

登录后烧录会读取芯片 MAC、登记到你的账号，并把 device_token 写入 NVS。可选填 Wi‑Fi，省去 SoftAP 配网。

选择上方产品

准备好 USB 线后再点安装。

用 PlatformIO 烧录
当前浏览器不支持 Web Serial。请换 Chrome / Edge，或用 PlatformIO。
注意
  1. 全量烧录会写入新的 NVS（含 token / 可选 Wi‑Fi），覆盖板上旧的配网与 token。
  2. ESP32-C3 Passport：选 USB JTAG/serial debug unit。ESP32-S3：按住 BOOT 再插线或复位进入下载模式。
  3. 烧录完成后设备会出现在控制台 → 设备。
