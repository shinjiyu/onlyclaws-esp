当前浏览器不支持 Web Serial。请换 Chrome / Edge，或用 PlatformIO。
注意
  1. 首次全量安装可能擦除 Flash（含 NVS 里的 Wi‑Fi / token）。已配过网的板子如需保留 NVS，请用仓库里的 safe_upload_keep_nvs.sh。
  2. ESP32-S3 原生 USB：按住 BOOT 再插线或点复位，进入下载模式后再点安装。
  3. 运维：在服务器上对对应 env 执行 rlcd/scripts/package_web_flash.sh <env> 生成 server/firmware/<id>/。
